1. What is Python?
Theory (English):

Python is a high-level, interpreted, general-purpose programming language. It is used to develop websites, software, applications, automation tools, and artificial intelligence systems.

Explanation (Roman Urdu):

Python aik programming language hai jis ki madad se hum computer ko instructions dete hain ke usay kya kaam karna hai.

Jaise hum kisi insan ko kehte hain ke calculator par 5 + 5 calculate karo, isi tarah Python ke zariye hum computer ko kehte hain ke 5 + 5 calculate karo.

Example:
print(5 + 5)



Output:
10


Example ki explanation:
- print() computer ko batata hai ke screen par result show karo.
- 5 + 5 aik mathematical calculation hai.
- 10 iska result hai.
Yani humne Python ko instruction di aur Python ne humein answer de diya.
2. Who Created Python?
Theory (English):

Python was created by Guido van Rossum. Its development started in 1989, and it was first released in 1991.

Roman Urdu Explanation:

Python ko Guido van Rossum naam ke programmer ne banaya tha. Unhon ne 1989 mein is par kaam shuru kiya aur 1991 mein Python pehli baar release hui.










3. Features of Python
Theory (English):

Python has many useful features that make it easy to learn and use. Some important features are:
1. Easy to Learn: Python has simple and readable syntax.
2. Interpreted Language: Python code is executed by an interpreter.
3. High-Level Language: Programmers do not need to manage low-level computer operations directly.
4. Portable: Python programs can run on different operating systems.
5. Open Source: Python is freely available to use and modify.
Roman Urdu Explanation:
- Easy to Learn: Python ki language simple hoti hai, is liye beginners asaani se seekh sakte hain.
- Interpreted: Python interpreter code ko execute karta hai.
- High-Level: Humein computer ki complicated internal instructions khud likhne ki zaroorat nahi hoti.
- Portable: Python Windows, Linux aur macOS par chal sakti hai.
- Open Source: Python free hai aur developers is mein improvements bhi kar sakte hain.

5. Your First Python Program
Theory (English):

A Python program is a set of instructions written to perform a specific task.

Example:
print("Hello World!")print("My name is Momil")print("I am learning Python")



Output:
Hello World!
My name is Momil
I am learning Python


Roman Urdu Explanation:

Yahan humne print() function teen baar use kiya hai.
- First line screen par Hello World show karegi.
- Second line screen par My name is Momil show karegi.
- Third line screen par I am learning Python show karegi.
Python instructions ko execute karke output display karta hai.
